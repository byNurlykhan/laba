# Әдіскерлер кабинеті: орнату және іске қосу

Кабинет бар стекте жұмыс істейді. Мұнда жаңа сервер немесе хостинг жоқ:

- **Сайт:** GitHub Pages (`index.html` және кабинетке арналған `cabinet.js`).
- **Сервер:** Google Apps Script (`apps-script/Code.gs`). Барлық рұқсат осы жерде тексеріледі.
- **Дерекқор:** «Лаба базасы» Google Sheets кестесі.
- **Word/Excel есептері:** `vendor/` қалтасындағы `docx` (Word), `ExcelJS` (Excel жасау) және `SheetJS` (Excel/CSV файлын оқу) кітапханалары. Есеп браузерде жасалады, ал деректерді сервер тек пайдаланушының аймағы бойынша береді.
- **Логотип:** `img/laba-logo.png`. Ол сайттың бүйір панелінде, сондай-ақ Word, Excel, график суреті (PNG) және басып шығару беттерінің жоғарғы жағында шығады. Логотипті ауыстыру үшін осы файлды ауыстыру жеткілікті.

## 0. Сақтық көшірме (міндетті)

1. **Кесте:** «Лаба базасы» кестесін ашып, **Файл → Көшірме жасау** арқылы көшірмесін жасаңыз (атауы: `Лаба базасы — көшірме ГГГГ-АА-КК`).
2. **Скрипт:** Apps Script-тегі `Код.gs` файлының қазіргі мазмұнын мәтін файлына сақтап қойыңыз.
3. **Сайт:** сайттың бұрынғы нұсқасы GitHub-та сақтаулы (әр өзгеріс жеке PR арқылы енгізілген).

## 1. Скриптті жаңарту

1. Кестеде **Кеңейтімдер → Apps Script** бөлімін ашыңыз.
2. `Код.gs` мазмұнын репозиторийдегі `apps-script/Code.gs` файлымен **толық** ауыстырып, **Ctrl+S** басыңыз.
3. Функция тізімінен **`setupCabinet`** таңдап, **▶ Run** басыңыз. Google рұқсат сұрайды (сыртқы сайтқа сұрау жіберу, кестеге жазу). Рұқсат беріңіз.
4. Орындалған соң төменгі **Execution log** (немесе кестедегі терезе) мынаны көрсетеді:
   - «Тізілім» парағы сайттың дерек файлдарынан құрылғаны (3 875 кітапхана);
   - «Мұрағат» парағына 3 875 кітапхананың **2025 жылғы қорытынды** паспорты сақталғаны. Бұрынғы нұсқа деректерді «2026 жыл, III тоқсан» деп жазған болса, ол жолдар «Тоқсандық» парағынан өзі алынады;
   - **бас әкімшінің логині (`admin`) мен уақытша паролі**. Парольді бірден көшіріп алыңыз.
5. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** жасаңыз. Баптаулары бұрынғыдай қалуы керек: *Execute as: Me*, *Who has access: Anyone*. Сайттың мекенжайы (URL) өзгермейді.

`setupCabinet`-ті қайта іске қосу қауіпсіз: бар деректер өшірілмейді және қайталанбайды.

Кестеде мына парақтар пайда болады:

| Парақ | Мазмұны |
|---|---|
| Тізілім | Кітапханалардың тұрақты деректері (атауы, мекенжайы…) |
| Тоқсандық | Тоқсандық есептер: бір кітапхананың бір тоқсаны бір жол, барлық өріс (паспорттың 2–6 бөлімдері + қосымша көрсеткіштер), күйі (жоба / бекітуде / бекітілді / қайтарылды), кім жіберді, кім бекітті. 2026 жылдан бастап толады. Жаңа өрістердің бағандары өзі қосылады |
| Мұрағат | Жыл сайынғы толық паспорттар: бір кітапхананың бір жылы бір жол. Парақ қорғалған. Алғашқы жыл: 2025 |
| Пайдаланушылар | Аккаунттар. Пароль тек хэш түрінде сақталады |
| Бірліктер | Аймақтар иерархиясы: `KZ` → `O:облыс` / `C:Астана…` → `D:облыс\|аудан` |
| Кітаптар | «Кітапханалар не оқып, не ұсынып жатыр?»: негізгі кітапхананың ұсыныстары мен ең көп оқылған кітаптары (түрі, санаты, орны, автор, атауы, тілі, жанры, оқылу саны) |
| Журнал | Барлық өзгеріс. Парақ қорғалған, әр жолда хэш тізбегі бар |

> **Ескерту:** «Тоқсандық», «Мұрағат», «Пайдаланушылар» және «Журнал» парақтарын қолмен өзгертпеңіз. Журналдың тұтастығын **LABA → Журналдың тұтастығын тексеру** мәзірі арқылы тексеруге болады.

## 2. Сайт

Сайттың файлдары (`index.html`, `cabinet.js`, `vendor/`) GitHub Pages-те өзі жаңарады. Беттің жоғарғы оң жағында **«Кіру»** батырмасы бар, ол `…/laba/#login` бетін ашады.

## Әр кезеңді тексеру

| Кезең | Не істеу керек | Күтілетін нәтиже |
|---|---|---|
| **Кіру және рөлдер** | `admin` болып кіріңіз. **Аккаунттар** бетінде аудандық әдіскер жасаңыз, сосын басқа браузерде сол әдіскер болып кіріңіз | Әдіскер тек өз ауданының кітапханаларын көреді |
| | Әдіскердің браузерінде сілтемені `#cabinet/lib/1/2026/4` деп өзгертіңіз | «Бұл кітапхана сіздің аймағыңызға кірмейді» |
| | Парольді 5 рет қате енгізіңіз | Аккаунт 15 минутқа бұғатталады. Әкімші парольді ауыстырса, бұғат алынады |
| **Тоқсандық есеп** | Аудандық әдіскер: кітапхана → тоқсан → бір өрісті толтырып, **Жоба ретінде сақтау** | Тізімде «Жоба» |
| | Барлық өрісті толтырып, **Бекітуге жіберу** | «Бекітуде»; облыстық әдіскердің **Бекіту** бетінде пайда болады |
| | Облыстық әдіскер: **Бекіту** → есепті ашу → **Сақтау және бекіту** | «Бекітілді»; ашық сайттағы паспортта жаңа мәндер |
| | Кітапхана беті → «2026 жылдық есеп» → Word | I–IV тоқсан және жыл бағандары бар құжат |
| | Бас әкімші → **Жиынтық** → Excel | Барлық кітапхананың барлық өрісі |
| | Кітапхана → IV тоқсан → мәнді «abc» деп жазыңыз | Өріс қызыл болып, «Міндетті өріс» / «Бүтін сан…» деп көрсетіледі |
| | Дұрыс мән енгізіп, **Сақтау** басыңыз | «Растаңыз» терезесі ашылады (ескі → жаңа мән, 50%-дан асқан өзгеріс туралы ескерту) |
| | Сақтағаннан кейін III тоқсанды ашыңыз | Ескі деректер өшпеген. Тізімде «Толтырылды · күні · аты-жөні» жазуы шығады |
| **Журнал** | `admin` → **Журнал** | Кім, қашан, қай кітапхана, қай өріс, ескі/жаңа мән, деңгейі |
| | Облыстық әдіскер → **Өзгерістер тарихы** | Тек өз облысының өзгерістері (мәндерсіз) |
| | Кестеде **LABA → Журналдың тұтастығын тексеру** | «Журнал бүтін» |
| **Google Sheets** | Әдіскер мәнді сақтағаннан кейін кестенің «Журнал» парағын ашыңыз | Уақыт, пайдаланушы, деңгейі, аймақ, мекеме, кітапхана, жыл, тоқсан, өріс, ескі мән, жаңа мән |
| | Телефонда интернетті өшіріп, мәнді сақтаңыз | «Кезекке қойылды» деген хабар шығады. Интернет қосылғанда өзгеріс өзі жіберіледі |
| **Сандар тілінде** | Бірнеше есеп бекітілген соң сайттың басты беті → жоғарыдағы жыл → **2026** | Сары жолақ (алдын ала, қай тоқсандар), сандар есептерден; 2025-ке қайтқанда бұрынғы сандар |
| **Word/Excel** | **Есептер** → сүзгілер → **Word** | Альбомдық кесте. Соңында жауапты мамандар (аты-жөні, телефон), соңғы жаңарту күні және жүктелген уақыт |

## Әзірлеушіге: автоматты тесттер

```bash
node tools/test/api-test.js     # 130 серверлік тексеру (Apps Script эмуляторында, нақты тізіліммен)
```

`tools/test/gas-emulator.js` — Code.gs-ті Node.js-те іске қосатын жеңіл эмулятор (SpreadsheetApp, CacheService т.б.).

## Шектеулер

- **Сессия:** 2 сағат әрекетсіз тұрса немесе 12 сағаттан кейін жабылады. Браузер қойындысы жабылса да сессия аяқталады.
- **Журналдың өзгермейтіндігі:** журналды тек жүйе жазады, парақ қорғалған. Бірақ кестенің иесі оны техникалық тұрғыдан қолмен өзгерте алады. Ондай өзгерісті хэш тізбегі анықтайды (тексеру мәзірі).
- **Жүктеме:** Apps Script бір мезетте шамамен 30 сұрауды өңдейді, бір сұрау 1–3 секунд алады. Бірнеше жүз әдіскерге бұл жеткілікті.
- **Тоқсандық өрістер:** тоқсан сайын тек `CAB.Q_FIELDS` тізіміндегі өрістер жаңартылады (қазір 6.1–6.3). Тізімді `Code.gs`-тің басында өзгертуге болады.
